# Student Grade Management Application

A Streamlit application backed by SQLite to manage students, record subject marks, calculate totals, averages, and assign letter grades.

## Features
- Add student records.
- Enter and update marks for multiple subjects.
- Automatically calculate total marks, average, and letter grade.
- View all student records and grade summaries.

## Installation & Running
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

## Running Tests
```bash
pytest tests/
```
